# Сравнение массивов чисел

Массив 1 можно ввести текстом или распознать с фотографии; массив 2 распознаётся с фотографии. Поддерживаются целые числа от 0 до 99, не более 54 значений. На телефоне кнопки открывают камеру или галерею, фото загружается автоматически. После распознавания сравнение запускается само. Массив 1 сохраняется в браузере этого устройства.

Для билета «Русское лото» приложение автоматически находит красный логотип, обрезает левую часть с логотипом и номером билета, увеличивает сетку и распознаёт только числа из клеток. На присланном образце это 30 чисел из шести строк; длинный номер билета внизу не должен попасть в массив. Поддерживаются фото JPG, PNG, WEBP и HEIC/HEIF (частый формат снимков с iPhone), размер файла — до 30 МБ.

Распознавание выполняется локальным OCR-движком Tesseract на сервере приложения. Фото не отправляется в облачный OCR-сервис; плата за каждый снимок не взимается. Для билета сетка предварительно обрезается, увеличивается, затем каждая клетка распознаётся отдельно — цифры соседних клеток не склеиваются. OCR может ошибаться, поэтому проверьте числа перед сравнением.

## Установка OCR

При размещении через Docker Tesseract устанавливается автоматически. На телефоне ничего устанавливать не нужно.

## Локальный запуск

На Linux установите Tesseract OCR (`sudo apt-get install tesseract-ocr`), затем выполните:

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Чтобы открыть сайт на телефоне в той же Wi-Fi-сети, запустите `python3 app.py --host 0.0.0.0`, затем перейдите на телефоне по адресу `http://<IP-адрес-компьютера>:8000`.

## Размещение по ссылке

В папке есть `Dockerfile`, который при сборке устанавливает Tesseract и Python-зависимости. Для Render подключите репозиторий и выберите Docker. Приложение слушает порт из `PORT` на адресе `0.0.0.0`. После публикации посетители открывают HTTPS-ссылку с телефона без установки программ. Чтобы обновление заработало на уже опубликованном сайте, отправьте изменённые файлы в подключённый репозиторий и дождитесь новой сборки.

## Как считать совпадения

- **Без учёта порядка** — сравнивает значения как мультимножества: каждое повторение учитывается отдельно. Например, для массива 1 `2, 2, 5` и массива 2 `2, 5, 5` совпадут два числа.
- **Только одинаковые позиции** — засчитывает числа, совпавшие на одном и том же месте.

Приложение отклоняет числа больше 99 и массивы длиннее 54 значений. Для билета с красным логотипом слева локальный OCR обрабатывает только обрезанное и увеличенное поле с клетками.
