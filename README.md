# Сравнение массивов чисел

Массив 1 можно ввести текстом или распознать с фотографии; массив 2 распознаётся с фотографии. Поддерживаются целые числа от 0 до 99, не более 54 значений. На телефоне кнопки открывают камеру или галерею, фото загружается автоматически. После распознавания сравнение запускается само. Массив 1 сохраняется в браузере этого устройства.

Для фотографий подключён нейросетевой сервис Yandex Vision OCR с моделью `handwritten`. Фото передаётся сервису Яндекса на распознавание. Нейросеть может ошибаться, поэтому приложение показывает результат в поле массива и просит проверить его до сравнения.

## Подключение Yandex Vision OCR

Нужны API-ключ Yandex Cloud с доступом к Vision OCR и ID каталога, в котором будет использоваться сервис.

1. В Yandex Cloud создайте сервисный аккаунт и выдайте ему роль `ai.vision.user`.
2. Создайте для него API-ключ с областью действия Vision OCR (`yc.ai.vision.execute`).
3. Скопируйте ID каталога.
4. На сервере задайте переменные `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. Для рукописных чисел используется модель `handwritten`; при необходимости её можно изменить переменной `YANDEX_OCR_MODEL`.

Не публикуйте ключ в GitHub и не вставляйте его в код. В Render добавьте ключ и ID каталога в **Environment → Add Environment Variable**. Переменные доступны только серверу и не отправляются в браузер.

Vision OCR тарифицируется за каждый запрос. На странице тарифов Yandex AI Studio сейчас указано 1,52 ₽ за распознавание рукописного текста; цена может измениться. Перед включением сервиса проверьте [актуальные тарифы](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing).

## Локальный запуск

```bash
python3 -m pip install -r requirements.txt
export YANDEX_API_KEY="ваш-ключ"
export YANDEX_FOLDER_ID="id-каталога"
python3 app.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Чтобы открыть сайт на телефоне в той же Wi-Fi-сети, запустите `python3 app.py --host 0.0.0.0`, затем перейдите на телефоне по адресу `http://<IP-адрес-компьютера>:8000`.

## Размещение по ссылке

В папке есть `Dockerfile`, который устанавливает Python-зависимости при сборке. Для Render подключите репозиторий и выберите Docker. Приложение слушает порт из `PORT` на адресе `0.0.0.0`. После публикации посетители открывают HTTPS-ссылку с телефона без установки программ.

## Как считать совпадения

- **Без учёта порядка** — сравнивает значения как мультимножества: каждое повторение учитывается отдельно. Например, для массива 1 `2, 2, 5` и массива 2 `2, 5, 5` совпадут два числа.
- **Только одинаковые позиции** — засчитывает числа, совпавшие на одном и том же месте.

Приложение отклоняет числа больше 99 и массивы длиннее 54 значений. Фото уменьшается только до лимитов Vision OCR, чтобы не терять мелкие цифры без необходимости.
