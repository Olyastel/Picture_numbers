# Сравнение массивов чисел

Веб-приложение: массив `м1` можно ввести текстом или распознать с фотографии; массив `м2` распознаётся с фотографии. На телефоне кнопки открывают камеру или выбор фотографии; снимок отправляется автоматически, после распознавания сравнение запускается само, когда оба массива заполнены. `м1` сохраняется в браузере этого устройства.

Пользователям не нужно устанавливать Python, Pillow или Tesseract: зависимости нужны только серверу, на котором размещено приложение.

## Что нужно установить

- Python 3.10 или новее
- Tesseract OCR
- Python-библиотека Pillow

Установка Pillow:

```bash
python3 -m pip install -r requirements.txt
```

Установите Tesseract для своей операционной системы и убедитесь, что команда `tesseract` доступна в терминале. Для macOS подойдёт `brew install tesseract`, для Debian/Ubuntu — `sudo apt install tesseract-ocr`. Для Windows установите Tesseract OCR и добавьте путь к `tesseract.exe` в `PATH`.

Если Tesseract не находится автоматически, задайте путь к исполняемому файлу через переменную `TESSERACT_CMD`.

## Запуск

В терминале перейдите в папку `outputs` и выполните:

```bash
python3 app.py
```

Затем откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Остановить сервер можно сочетанием `Ctrl+C`.

## Размещение для доступа с телефона по ссылке

Для постоянной ссылки нужен сервер или облачный хостинг с поддержкой Docker. В папке есть `Dockerfile`, который устанавливает Python-зависимость Pillow и системный Tesseract один раз при сборке серверного образа. Опубликуйте образ на выбранном хостинге; приложение слушает порт из переменной `PORT` и адрес `0.0.0.0`. После публикации пользователь открывает HTTPS-ссылку на телефоне и устанавливает ничего.

При разработке можно открыть приложение с телефона в той же Wi-Fi-сети: запустите `python3 app.py --host 0.0.0.0`, затем откройте на телефоне `http://<IP-адрес-компьютера>:8000`. Это временный адрес, пока компьютер и сервер включены.

## Как считать совпадения

- **Без учёта порядка** — сравнивает значения как мультимножества: каждое повторение учитывается отдельно. Например, для `м1 = 2, 2, 5` и `м2 = 2, 5, 5` совпадут два числа.
- **Только одинаковые позиции** — засчитывает числа, совпавшие на одном и том же месте.

Поддерживаются целые и десятичные числа; десятичный разделитель — точка. Для корректного результата проверьте распознанный массив `м2`: качество фото влияет на точность OCR. Изображения обрабатываются локально и не отправляются в интернет.
